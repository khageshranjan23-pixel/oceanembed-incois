      INTERPRETATION

      What these values mean

      Temperature
      Ocean temperature in °C, adjusted to a surface pressure reference so values at different depths can be compared.
      Anomaly
      How much the prediction differs from the seasonal reference calculated from training data. Positive means warmer; negative means cooler.
      Uncertainty
      The width of the calibrated prediction interval, where available. Read it with the accuracy and coverage results.
